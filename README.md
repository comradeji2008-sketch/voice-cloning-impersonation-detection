# AI-Powered Real-Time Detection and Prevention of Voice Cloning Impersonation Attacks

## Smart India Hackathon Project

An AI-powered system designed to detect and prevent voice-cloning-based
impersonation attacks in real time.

## Problem Statement

Voice cloning technology can be misused to impersonate individuals and
perform fraudulent activities. This project aims to identify synthetic
or cloned voices and prevent impersonation attacks using AI/ML techniques.
